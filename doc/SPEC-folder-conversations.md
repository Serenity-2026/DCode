# 按文件夹组织会话

- 每段会话创建时固定保存绝对工作目录，不再从消息附件推断。新建会话立即打开目录选择器；取消选择时，在系统文档目录的 `DCode` 下创建 `dcode-YYYYMMDD-随机数` 目录。
- 选择目录不读取目录内容。附件仍作为文本快照，不能改变会话工作目录。首次直接发送且尚无会话时，也先完成目录选择和会话创建。
- 侧栏以完整目录路径分组，显示目录名和其下会话；同名不同路径分开。目录行支持折叠、展开及右键“在此文件夹下新建对话”，复用已授权的目录而不再次打开选择器。目录不存在时新建失败并保留原会话。
- 空会话立即保存，第一条消息生成标题；导航切换、重试和重启保留目录。不同账号的分组独立。删除会话不删除磁盘目录。
- 存储改用 schema 4，不提供旧格式兼容或迁移逻辑。本工作区已有聊天按用户要求清空，保留账号和服务设置。
- 钢琴键消息导航固定在聊天滚动区域左侧垂直居中，保持原有跳转、悬浮预览和滚动行为。

验证目录选择/默认创建、账号归属、固定目录上下文、空会话及重启、同名目录分组、右键新建、并发任务和导航居中；使用临时数据目录，不访问真实模型服务。
