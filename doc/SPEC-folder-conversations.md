# 项目与文件夹会话

- 每段会话创建时固定保存绝对工作目录，不再从消息附件推断。新建会话立即打开目录选择器；取消选择时，在 `app.getPath('userData')/workspaces` 下创建 `dcode-YYYYMMDD-随机数` 目录。默认根目录由 Electron 按运行环境定位，不写死用户名、盘符或文档路径。
- 选择目录不读取目录内容。附件仍作为文本快照，不能改变会话工作目录。首次直接发送且尚无会话时，也先完成目录选择和会话创建。
- 侧栏以完整目录路径分组，显示目录名和其下会话；同名不同路径分开。目录行支持折叠、展开及右键“在此文件夹下新建对话”，复用已授权的目录而不再次打开选择器。目录不存在时新建失败并保留原会话。
- 文件夹行采用线框文件夹图标和单行名称，不显示箭头和数量；展开/收起使用打开/关闭图标区分，长名称省略，完整路径保留悬浮提示。
- 侧栏分组标题为可点击的“项目”：有展开项时点击收起全部，再次点击展开全部；右侧加号打开“创建项目”表单。输入项目名，选择父目录后在其中创建同名子目录；未选择位置时使用应用默认工作区。创建成功保存首段空会话并进入该项目，取消保留原草稿。同名文件/目录不覆盖，非法项目名或未经原生选择器确认的位置拒绝创建。
- 会话列表通过高度过渡向下展开，条目按顺序淡入并下落；折叠时反向收起，隐藏列表不参与键盘焦点。搜索时展开分组以展示匹配项，之后仍可点击“项目”统一折叠。动画尊重减少动画偏好。
- 右键“删除文件夹”在确认后移除当前账号该目录下全部对话和侧栏分组，保留真实目录与文件。搜索只过滤展示，不缩小删除范围；确认框显示全部对话数量。目录中有任务运行时禁用删除，主进程也检查整个分组；其他文件夹任务继续运行。删除当前分组回到欢迎页，删除其他分组保留当前会话和草稿。一次事务保存全部删除结果，失败回滚；不影响其他账号的同路径分组。
- 空会话立即保存，第一条消息生成标题；导航切换、重试和重启保留目录。不同账号的分组独立。删除会话不删除磁盘目录。
- 存储改用 schema 4，不提供旧格式兼容或迁移逻辑。本工作区已有聊天按用户要求清空，保留账号和服务设置。
- 钢琴键消息导航固定在聊天滚动区域左侧垂直居中，保持原有跳转、悬浮预览和滚动行为。
