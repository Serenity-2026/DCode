# 输入框工具与附件 SPEC

日期：2026-10-03 · 状态：已实现并验证

## 工具栏

- 左下角新增加号，下拉菜单的“添加”分组提供“添加文件”“添加文件夹”，分别打开系统选择器。
- 右侧依次放置模型菜单、上下文圆环、快速模式和强度入口；点击入口展开强度滑块，发送按钮位于最右端。窄窗口允许工具组换行，避免挤出窗口。
- 模型选择和快速模式沿用当前账号的配置与请求行为。
- 模型入口箭头朝上，对应上方展开的菜单。浅色菜单使用白底、浅灰绿选中背景与深色文字；深色菜单使用浅色文字，选中和悬浮状态保留足够对比度。配色仅作用于模型菜单。
- 强度使用 Ant Design Slider，轨道两端圆形、渐变填充、圆形滑块与随档位变化的光晕；悬浮显示档位，支持键盘操作，减少动态效果的系统偏好关闭动画。

## 文件与文件夹

- 选择后显示附件标签，可以移除；发送时把读取的文本附加到模型上下文，历史消息保留附件名称与当时的文本快照，重试不重新读取文件。
- 本次支持 UTF-8 文本/代码；二进制、非 UTF-8、空文件、符号链接不作为文本附件。文件夹递归读取，跳过隐藏项、node_modules、构建输出，不跟随符号链接；不执行文件。
- 文件夹不设单文件大小、总大小、文件数量或遍历数量上限，允许空目录。独立文件保留每文件 128 KiB、每次选择 50 个文本文件、每条消息 10 个独立文件附件及合计 512 KiB 的限制；目录不计入这些限额。
- 仅读取系统选择器实际选择的路径。IPC 不提供任意路径读取入口；取消选择不改变草稿，读取失败保留已有附件和输入。附件只在发送成功后或切换会话时清空，随账号切换销毁。

## 上下文与强度

- 从服务 `/models` 的 `context_window`（兼容 `context_length`、`top_provider.context_length`）、`effort.supported_levels` 读取模型元数据，不按模型名称猜测。
- 圆环比例为当前请求的预估输入 token / 上下文窗口。与模型请求共用上下文构建函数，包含系统提示、有效历史轮次、当前草稿、附件；不计失败历史或隐藏推理。
- token 数按 UTF-8 字节数 / 3 向上取整加消息开销估计，不冒充服务端的精确用量；悬浮提示注明“预估”、窗口、已用、剩余。窗口未知显示未知状态，不能伪造百分比。
- 强度面板只显示当前模型 `/models` 返回的 `effort.supported_levels`，按强度排序、去重；例如 DeepSeek Flash 只显示 low / high / max。选择后请求原样发送对应值，不再映射界面档位。
- 选择按账号、服务和模型分别保存，切换模型恢复该模型的选择。首次选择优先采用服务返回的 `effort.default_level`，否则取 medium 或最近受支持档位。旧账号全局偏好只迁移到当时选中的模型；无效旧档位及目录刷新后已移除的档位取最近受支持值。
- 缺少档位元数据时显示“强度未知”，不发送 reasoning_effort，使用服务默认行为；明确空列表时显示“不支持推理”。仅一档时显示该档位按钮，不提供无意义的滑动。保留连续拖动、释放吸附、键盘与减少动画偏好，轨道和选中胶囊宽度随档数变化。
- DeepSeek 有选中强度时同时启用 thinking；服务拒绝参数时提示调整强度。
