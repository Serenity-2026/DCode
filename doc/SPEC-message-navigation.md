# 对话左侧消息导航 SPEC

日期：2026-10-03

- 参考用户附图，消息区域左侧固定显示细短线，每轮用户问题对应一条；当前阅读轮次加长并高亮，其余短线按距离逐渐缩短。
- 悬浮或键盘聚焦短线显示圆角预览卡，包含真实问题、回复摘要、附件名称与时间；浅色和深色主题分别适配，预览尺寸受窗口限制。
- 点击短线平滑滚动至对应问题，保留草稿和附件；跳转阅读历史期间流式响应不强制拉回底部。系统减少动画偏好使用即时跳转。
- 手动滚动、内容高度变化、侧栏调整或窗口缩放时同步当前阅读位置；消息较多时导航区自身可滚动，不扩展页面高度。
- 新对话没有导航，切换会话重置导航与悬浮卡。支持 Tab 聚焦、Enter 跳转和 Escape 关闭预览。
- 用户本次选择先实现消息导航；收藏功能不在本次范围。
- 验证：多轮导航数量、预览内容、点击与键盘跳转、滚动高亮、流式阅读不回底、窄窗口/侧栏隐藏/深色、会话切换和减少动画偏好。
