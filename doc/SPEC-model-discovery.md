# 服务模型列表与快速模式 SPEC

日期：2026-10-03 · 状态：已实现并验证

本规范修正账号与模型设置 SPEC 中的手填模型 ID 和仅说明的闪电按钮。

## 服务与模型

- 设置只填写服务名称、Base URL 和 API Key，不选择或填写模型 ID。
- 主进程读取账号保存的服务地址和解密后的密钥，以 Bearer 认证请求 `GET <Base URL>/models`，解析实际返回的 `data[].id`；不内置任何模型名单。
- “测试并保存”改为请求模型列表进行认证与连通验证。列表非空且格式有效才保存服务及列表；失败提示原因，原配置不变。不自动向列表中的第一个模型发送付费聊天测试，避免误选非聊天模型。
- 每次登录/恢复登录后自动读取所有已配置服务的模型列表；输入区提供“刷新模型列表”入口。刷新失败保留上次成功获得的列表并提示用户。
- 输入区按服务显示模型，可选择该服务返回的任意模型 ID。选择后保存在当前账号，下一次请求使用该服务的 URL、API Key 与选中的模型。
- 不同账号的服务、列表、选择和快速模式分别保存；密钥不向界面回显。保留当前多服务配置能力。
- 数据升级到 schema 3，升级前备份 schema 2；保留账号、密码、会话、主题、服务地址和密钥。旧手填模型 ID 不作为服务返回列表，升级后重新获取。
- 模型列表请求 15 秒总超时，不跟随重定向；使用现有地址校验及系统安全存储。

## 快速模式

- 闪电按钮切换当前账号的快速模式；开启时蓝色实心闪电，关闭时灰色描边闪电，提供 `aria-pressed` 状态。
- 保留“仅对支持加速的模型生效”的提示；生成或模型列表刷新期间禁止修改选择。
- 用户已确认使用 `service_tier: "priority"`。开启时请求兼容服务的该参数，实际加速取决于服务和模型支持，不推断模型名称表示的加速能力；拒绝快速模式参数的请求提示关闭后重试。
- 普通模式不发送加速参数。已知 DeepSeek 官方接口不发送未声明支持的加速参数。

## 验证

- 单元测试：模型列表解析、空/异常/认证失败/超时回滚、编辑留空复用密钥、刷新后的选择修复、跨账号访问拒绝、schema 2 迁移。
- Electron E2E：设置无模型 ID 输入，菜单展示服务返回的多个模型，切换影响实际聊天请求；闪电开/关的颜色、图标和持久化状态；刷新错误提醒与旧配置保留。
- 类型检查、生产构建与打包；隔离账号验证真实 DeepSeek 模型列表及聊天。保留既有 AGENTS.md 改动，仅提交本任务文件，不推送。

验证记录：35 项单元测试及 2 项 Electron E2E 通过，其中包含真实 DeepSeek 列表获取与流式聊天。类型检查、生产构建、macOS 打包通过；打包应用验证 schema 2 升级、自动恢复登录、54 个模型的菜单滚动、长模型名称截断与快速模式持久化。设置弹窗居中，在 820 × 620 窗口下初次打开时保存按钮可见。

接口参考：[Models API](https://developers.openai.com/api/reference/resources/models/methods/list)、[Fast mode](https://developers.openai.com/api/docs/guides/fast-mode)。
