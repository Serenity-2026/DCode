# 服务模型列表与快速模式 SPEC

日期：2026-10-03 · 状态：已实现并验证

本规范修正账号与模型设置 SPEC 中的仅说明闪电按钮。2026-10-18 增加手动模型 ID，与自动发现并存，详见 [设置规范](SPEC-settings.md)。

## 服务与模型

- 设置填写服务名称、Base URL 和 API Key，可选填模型 ID（从已获取列表选择，或手动输入）。
- 主进程读取账号保存的服务地址和解密后的密钥，以 Bearer 认证请求 `GET <Base URL>/models`，解析实际返回的 `data[].id`；不内置任何模型名单。
- “测试并保存”改为请求模型列表进行认证与连通验证。列表非空且格式有效才保存服务及列表；失败提示原因，原配置不变。不自动向列表中的第一个模型发送付费聊天测试，避免误选非聊天模型。
- 填写模型 ID 时使用“保存配置”，直接保存且不声称连通测试通过；允许连接不提供模型列表接口的服务。手填模型保存在 `manualModels`，与服务目录合并到 `availableModels`；刷新时保留手填项。
- 每次登录/恢复登录后自动读取所有已配置服务的模型列表；输入区提供“刷新模型列表”入口。刷新失败保留上次成功获得的列表并提示用户。
- 输入区按服务显示模型，可选择该服务返回或手动保存的模型 ID。选择后保存在当前账号，下一次请求使用该服务的 URL、API Key 与选中的模型。
- 不同账号的服务、列表、选择和快速模式分别保存；密钥不向界面回显。保留当前多服务配置能力。
- 数据直接保存账号、密码哈希、会话、主题、服务地址和密钥密文。手填模型是可选字段，未填写的旧配置保持原有发现行为，不新增 schema 版本。
- 模型列表请求 15 秒总超时，不跟随重定向；使用现有地址校验及系统安全存储。

## 快速模式

- 闪电按钮切换当前账号的快速模式；开启时蓝色实心闪电，关闭时灰色描边闪电，提供 `aria-pressed` 状态。
- 保留“仅对支持加速的模型生效”的提示；生成或模型列表刷新期间禁止修改选择。
- 用户已确认使用 `service_tier: "priority"`。开启时请求兼容服务的该参数，实际加速取决于服务和模型支持，不推断模型名称表示的加速能力；拒绝快速模式参数的请求提示关闭后重试。
- 普通模式不发送加速参数。OpenAI 兼容协议只依据快速模式配置发送，不按服务域名特判；服务是否支持由实际响应决定，拒绝时提示关闭后重试。
