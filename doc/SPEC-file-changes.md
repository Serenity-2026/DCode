# 每轮文件变更与撤销

一轮指一次用户提问及其模型回复，包含该次回复内全部模型请求和工具调用。回复底部显示本轮通过 write、edit 修改的文件；同一路径合并成一行，增删行数按首次修改前与最后修改后的全文计算。已有文件净变化为零时不显示；新建空文件仍显示。卡片提供逐文件差异预览、逐文件撤销及撤销本轮剩余修改，撤销保留聊天正文和历史差异。

## 记录与持久化

- bootstrap 注入 FileChanges.record，ToolRuntime 固定当前 conversationId/messageId，write/edit 在同路径修改队列中把实际写操作交给记录器。Agent/AgentLoop/ToolExecutor 不依赖恢复实现。
- 修改前先把完整原文、预期写后内容与归属原子保存到 state.json 的可选 fileChanges 字段，保存失败不执行写入。副本按 base64 保存完整 UTF-8 字节，null 表示不存在，空字符串表示存在的空文件。保留 schema 4，旧数据无需新增字段也可读取；新增记录严格校验归属、路径、计数、预览与编码。
- 修改完成后保存实际磁盘结果；失败或取消已经产生的修改仍保留恢复副本。wx 因外部文件抢占而报 EEXIST 时不把外部文件计入本轮。停止/退出等待已开始的记录写入结算；运行期间拒绝在同一会话重新发送。
- 同一轮同一文件连续修改保留第一次修改前的副本；中间检测到其他操作改变文件时拒绝把它合并进本轮。重新生成仍属于原提问，变更记录转移到新的 assistant 消息，原始恢复点保留。
- 首次修改备份及写后状态不直接发往 renderer 或模型；renderer 仅得到文件名、增删行数、状态及有界预览，正文和 diff 各最多 2000 行或 50 KiB。恢复副本不截断。
- 重启核实 pending 记录：磁盘与预期写后相同时确认 applied，与原文相同时确认 reverted；其他情况不猜测，保留副本并在恢复时核对。删除会话或分组时清理对应备份，不删除工作区文件。

## 撤销边界

- IPC 只接受 conversationId、messageId 与可选 changeId，不接受任意磁盘路径。主进程校验登录、会话及变更归属。
- 有生成任务时禁用撤销，后端同样拒绝；撤销准备和执行期间沿用 IPC 互斥，避免新任务交错。整轮恢复以固定顺序取得全部目标路径队列。
- 整轮先核对全部目标：当前完整字节必须与记录的写后内容或已恢复原文一致。任一文件存在后续修改，整轮不开始恢复；仍可单独撤销其他文件。后续轮次或其他会话修改同一文件时，需要先撤销较新的修改。
- 已有文件恢复完整原文，使用同目录临时文件和 rename 原子替换，并保留当前权限；本轮新建文件撤销时删除。新建的父目录保留，不递归删除目录。每个文件恢复后保存状态，磁盘或保存中途失败时保留已完成进度，允许重试。
- 不跟随符号链接，不恢复硬链接或特殊文件，父目录真实位置变化时拒绝恢复。内容检查不是外部进程的系统级锁；不承诺跨进程事务或整轮磁盘恢复绝对原子性。
- Bash、外部编辑器和第三方工具产生的修改不追踪；旧工具记录只有截断预览，不能补造恢复副本。没有恢复后重做功能。

## 验证

单元测试覆盖重复修改合并、空文件、BOM/CRLF 原样恢复、有界预览与完整备份、备份隔离及重启、整轮冲突预检、跨会话顺序、重新生成、写入失败/取消、EEXIST 外部新文件、保存重试、账号隔离、链接/目录变化和损坏记录。Electron E2E 覆盖三文件卡片、净增删、差异、逐文件撤销、整轮冲突、重启恢复与窄窗口。
