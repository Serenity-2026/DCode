# 侧边栏调整 SPEC

日期：2026-10-03

- 会话按完整工作目录分组，目录名相同但路径不同的分开显示；目录行仅保留线框图标与名称，可折叠，右键提供“在此文件夹下新建对话”和“删除文件夹”。删除前确认全部对话范围，保留磁盘文件，运行中分组禁止删除。创建与存储规则见 `SPEC-folder-conversations.md`。
- “项目”标题控制全部分组展开/收起，右侧加号打开带项目名和父目录选择的创建表单；分组通过向下展开和条目依次淡入过渡，减少动画时即时切换。
- 使用 Ant Design Splitter，拖动侧栏右侧边界连续调整宽度，默认 246px，最多为当前应用窗口宽度的 1/3。
- 宽度拖到 180px 以下时自动收起；顶部按钮显示或隐藏侧栏，展开恢复本次会话中收起前的宽度。拖动收起时恢复该次拖动开始前的宽度。
- 窗口缩小时限制当前宽度，侧栏收起后主区域占满窗口。顶部按钮为 macOS 窗口按钮预留空间，保持可点击。
- 连续拖动不使用延迟过渡，按钮收起/展开使用 Splitter 动画，尊重系统减少动画偏好。
- 保留侧栏、对话与草稿，不在拖动期间调用 IPC 或重建聊天内容；隐藏侧栏不参与键盘焦点导航。
- 验证：拖动拉宽、1/3 上限、缩窄与阈值收起、按钮恢复、窗口缩小、隐藏后的草稿/会话保持、浅色与深色布局、减少动画偏好、构建与打包。

## 双击重命名聊天（2026-10-18）

- 双击侧栏中的聊天条目打开“重命名聊天”弹窗，预填并全选原标题；原有菜单中的重命名入口继续可用。
- 单击仍立即切换聊天，切换请求期间保留目标条目的双击事件，不重复提交第二次选择。点击已选中的聊天不清空草稿。
- 弹窗提供“取消”和“保存”，支持 Enter 保存、Esc 取消；中文输入法组合输入期间 Enter 不提交。空白名称不可保存，最多 80 个字符。
- 保存沿用 `conversation:rename`，仅更新目标聊天名称并持久化；失败保留弹窗及输入。提交期间防止重复保存和关闭。
- 采用圆角弹窗、蓝色输入焦点和简洁的操作按钮，适配深浅主题与窄窗口。
- Electron E2E 覆盖当前/非当前聊天双击、单击切换、草稿保留、空白校验、取消、两种保存方式与重启后名称恢复。
