# DCode 账号与模型设置 SPEC

版本：0.2 · 日期：2026-10-03 · 状态：实施中

本规范替代首版中的免登录用户档案、环境变量唯一配置和不可点击的模型标签。

## 账号与保持登录

- 提供本机账号注册与登录，账号 3–32 个字母、数字或 `_.-`（支持中文），密码 8–128 个字符。
- 密码通过随机盐与 scrypt 保存为哈希，不保存明文密码。登录成功后自动保持登录，重启直接进入工作台；主动退出后必须再次输入密码。
- 保持登录使用随机会话令牌，令牌由 Electron safeStorage 加密，磁盘只保存令牌密文与验证哈希；登录信息和密钥不返回 renderer。
- 所有聊天、模型配置与主题归属于账号。未登录的 IPC 不能读取聊天、发消息或修改设置；移除原来无需密码即可切换用户的入口。
- 注册与登录属于本机身份校验，不提供云端账户、联网注册或跨设备同步。OS 用户仍可读取本机聊天 JSON。
- 首版数据升级到 schemaVersion 2，升级前保留 `.v1.backup`。没有密码的旧档案在注册页可选择关联，保留原用户 ID 与会话。
- 不同账号的模型配置不共享；原环境变量配置仅导入首个注册账号，后续账号自行配置。

## 模型配置

- 设置页可添加及编辑多个 OpenAI 兼容模型配置：显示名称、Base URL、API Key、模型 ID。
- API Key 通过 safeStorage 加密保存；编辑时不回显密钥，留空使用该配置原有密钥。
- 点击“测试并保存”会向填写的 `/chat/completions` 发送一条短流式请求，15 秒空闲超时、最多 16 个输出 token。它可能产生少量 API 费用。
- 只有服务返回完整、非空文本，且 SSE 正常结束，才保存新配置并选中。401、429、地址错误、无效模型、超时或断流显示具体提示，原配置不变。
- 测试和保存由同一主进程方法完成，保证测试的是正在保存的准确配置；测试期间禁止重复提交、退出账号及切换配置。
- Base URL 必须 HTTPS，允许 localhost/127.0.0.1 的 HTTP 供本地服务使用；不跟随重定向。
- DeepSeek 官方服务使用非思考请求参数，其他兼容服务不强行发送 DeepSeek 专有参数。
- safeStorage 不可用或 Linux 使用 basic_text 时拒绝保存秘密，提示系统安全存储不可用，不降级到明文。

## 输入区与交互

- 输入区底部的模型名称改为真实下拉菜单，可切换账号下已保存的配置，并提供模型设置入口。
- 选择结果立即保存，下一条请求使用选中的配置；历史消息和当前会话继续保留。
- 小闪电成为独立可点击按钮，点击显示“仅对支持加速的模型生效”。本轮不增加未经服务支持的加速参数或假开关。
- 移除聊天 textarea 聚焦时的黑色内框，保留 composer 外层柔和边框提示，不影响其他表单与按钮的键盘焦点。
- 所有新类与核心方法延续中文职责、依赖与调用关系注释。

## 验收

1. 单元测试覆盖密码验证、重复账号、注销后的会话失效、保持登录恢复、账号隔离、旧数据迁移及秘密不出现在快照中。
2. 单元测试覆盖测试失败不保存、编辑留空复用原密钥、配置切换及通用/DeepSeek 请求参数。
3. Electron E2E 验证注册→聊天→关闭重启自动登录→退出→错误密码拒绝→正确密码登录，以及第二账号不可见第一账号聊天与配置。
4. E2E 验证模型添加/编辑成功、错误服务配置提示与原值保留、底部切换影响实际请求、闪电点击提示。
5. 聚焦输入框后检查实际 computed style，无黑色 outline/box-shadow，并检查登录页、配置弹窗与窄窗口布局。
6. 类型检查、单元测试、生产构建及 Electron E2E 通过。仅提交本任务文件，不提交环境文件与现有 AGENTS.md 修改，不 push。
