# 欢迎页云朵与文件夹选择

## 界面行为

- 欢迎标题上方使用灰色云朵终端轮廓，替代应用 D 图标；其他位置保持 D 图标。
- 云朵轻微漂浮，悬浮时提亮；点击平滑旋转一周并扩散光圈，重复点击继续旋转，支持键盘与系统减少动画偏好。
- 云朵内的短横线独立作为终端光标，持续明灭闪烁，每轮 1.1 秒，亮/灭切换带短淡入淡出；轮廓与提示箭头保持可见。系统减少动画时光标常亮。
- 未选择文件夹时标题为“今天想写点什么？”。
- 选择后标题为“今天想在 xxx 中写点什么？”，xxx 是文件夹名称，带下划线。
- 点击名称打开菜单，选择“选择文件夹…”调用系统目录选择器。重新选择替换草稿中的文件夹，保留独立文件与输入；取消或失败保留原选择。
- 移除文件夹后恢复默认标题。空文件夹也保留名称和零文件附件。

## 文件夹读取

- 文件夹不设单个文本文件大小、文本总量、文件数量或遍历数量上限；IPC、草稿和历史校验同样不限制这些字段。
- 独立文件沿用原有规则，文件夹内容不计入独立文件的数量、大小限额。
- 继续跳过隐藏项、依赖与构建目录、二进制、非 UTF-8、空文件和符号链接，读取错误明确返回，不截断文本。
- 仍以文本快照发送模型上下文。服务端实际上下文窗口及本机资源决定可处理规模，应用不另外设置文件夹配额。

## 验证

- 单元测试覆盖超过 128 KiB 的单文件、超过 512 KiB 的目录、超过 50 个文件、空目录、非法附件，以及大文件夹快照保存和重试。
- Electron E2E 覆盖云朵实际旋转、短线实际亮灭循环、减少动画时常亮、标题名称与下划线、菜单换目录、取消保留、空目录与移除恢复、实际请求内容。
- 类型检查、生产构建、macOS 打包及应用实际欢迎页显示。

验证记录：49 项单元测试通过；2 项相关 Electron E2E 通过，覆盖旧附件工具及新增欢迎页、旋转与减少动画、更换/取消/空目录、61 个文件与 600 KiB 文本完整发送。类型检查、生产构建与 macOS 打包通过；打包应用实际选中 DCode 的 53 个文本文件，确认标题、下划线、目录菜单和移除恢复。
