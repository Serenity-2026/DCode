# 输入区域与模型强度动效

日期：2026-10-03

- 模型生成时，鼠标进入输入区域显示跟随指针的旋转圆环，替换禁用鼠标图标；移出后隐藏，停止或完成生成后移除。输入的禁用规则与停止按钮保持原行为。
- 模型强度轨道从 5px 加粗到 8px，圆形滑块与轨道保持中心对齐；已选中的彩色进度区域内持续流动细小粒子，不遮挡拖动、点击或键盘操作。
- 动画使用 CSS 旋转和位移；鼠标位置直接更新局部 CSS 变量，不触发预览或消息重渲染。系统减少动画时关闭旋转与粒子流动。
- 验证生成时的悬停、位置跟随、持续旋转、移出隐藏、停止恢复；验证轨道尺寸、滑块对齐、粒子动画、原有拖动/键盘/不同模型档位、深色及窄窗口。

## 验证记录

- 账号/模型/流式恢复、附件/上下文/模型强度两项 Electron 场景通过。新增检查覆盖真实旋转与位移变化、圆环跟随精度、移出隐藏和停止清理、8px 轨道及滑块垂直中心对齐、减少动画偏好。
- 模型设置的失败配置测试改用键盘提交，避免清除结果提示后布局变化干扰鼠标点击；生产设置逻辑没有修改。
- 类型检查、生产构建和 macOS arm64 打包通过；实际桌面版已检查加粗轨道、居中的滑块和粒子外观。
